# Blog publishing

Use `sundeep-sf/sundeep-sf.github.io` for all blog content, site changes, and publishing. The separate `sundeep-sf/sundeep-sf` repository is for the GitHub profile only.

Before adding or changing a note or its outline, read `content/README.md` for the authoring workflow. Commit source changes with their generated HTML, and verify `npm test` passes before opening a pull request.
